# Encryption Schemes in Blockchain

## Definition

An **encryption scheme** is a cryptographic technique used to convert **plaintext (readable data)** into **ciphertext (unreadable data)** so that only an authorized person can access the original information.

## Basic Concept

```text
Plaintext
    ↓
Encryption + Key
    ↓
Ciphertext
    ↓
Decryption + Key
    ↓
Plaintext
